# MVP仕様書 — Pixel FX Studio

## 目的

既存OSS `patch-gg/pixelfx` のエフェクトをローカルWebアプリで選択・再生・PNG保存する。研究用途やゲーム素材作りにつながる小さな成果物を作り、複雑な外部サービス統合を避ける。

## ユーザーストーリーと受け入れ条件

### P1. エフェクト選択
- スクロール可能な一覧から、**pixelfxの全244種類**のエフェクトを選べる（初期3種類から利用者の追加依頼で拡張）。件数は公式の登録内容から自動表示する。
- 選択中の効果名を表示する。
- 全244種類の日本語名と公式の英語名を併記し、実描画から生成したサムネイルをギャラリーに表示する。
- 最初の32種類の順番を維持し、連続攻撃・衝撃・画面切り替えを含む全21カテゴリを収録。公式の `pixelfx/fx/index` で実在を確認する。全種類は `EFFECT_CATALOG.md` に記載。
- カテゴリで一覧を絞り込め、表示件数を示す。現在の効果が対象外の場合はカテゴリの最初の効果を表示し、一時停止状態は保つ。全件へ戻した場合も選択中のカードが見えるようにする。
- 名前・ID・説明・タグ・日本語カテゴリを検索でき、カテゴリと併用できる。大文字小文字・全角英字の差を吸収し、複数語はすべて一致するものを表示する。0件の場合は案内を表示し、現在のプレビューは維持する。
- 日本語名も検索できる。スマートフォンではプレビューと操作部を先に表示し、その下で3列の一覧をスクロールできる。矢印キーで移動した選択項目も表示範囲に入る。

### P2. Canvasでアニメーション
- Canvas内で選択した効果が動く（画面解像度例 320×180、CSS拡大）。
- 最小Canvasは320×288とし、大型の効果では元サイズに合わせて拡張する。表示サイズを画面に示し、通常の効果に戻すと最小サイズへ戻す。
- 連続攻撃は公式createAct/actBoundsでキャラクター・対象・予備動作を再生し、画面切り替えは公式の星空背景に重ねる。
- 切り替え時、前のアニメーション処理を停止・破棄し、新しい効果のみ描画する。
- `pixelfx` が提供する `createFrame` / `createFx` / `clearFrame` / `composite` をベースに、公式READMEのコードに沿って実装する。
- 一時停止・再開ボタンで、現在のフレームを固定し、続きから再開できる（追加候補から実装済み）。
- 停止中に別の効果を選んでも停止状態を維持する。停止時間は再開後の経過時間に加算しない。
- コマ送りで停止して1フレーム進められる。リスタートは停止状態を維持し、フレーム番号を0に戻す。
- Fit・2倍・4倍表示を選べる。Fitは元のエフェクト領域に合わせ、拡大中はドラッグで移動、ダブルクリックでFitへ戻す。元のCanvas解像度と保存画像は変えない。
- プレビューにフォーカスしてSpace・右矢印・Homeで再生停止・コマ送り・リスタートができる。表示倍率・フレーム番号を示す。

### P3. PNG保存
- 現在のCanvas表示がPNGで保存できる。
- 保存サイズは選択中のCanvasの実サイズに一致する。
- 一時停止中も、その表示フレームをPNGとして保存できる。
- 名前は `pixelfx-<effect-slug>.png` など安全な形式とする。
- 保存不可・Canvas未生成の場合はユーザー向けにエラーを示す。

## MVPの範囲外

GIF/動画出力、スプライトシート生成、エフェクト作成AI、パレット編集、バックエンド、ユーザーログイン、アップロード。

## 技術構成

- Node.js 22.12+、Vite、vanilla TypeScript
- `pixelfx` GitHub依存：`github:patch-gg/pixelfx`（事前にAPI互換を確認）
- テスト：Vitest（外部画面を必要としないユニットテスト中心）
- 想定URL：`http://localhost:5173/`

## 実装候補構成

```
src/
  main.ts              # UI・DOM制御
  effects.ts           # 検証済みエフェクト登録
  renderer.ts          # アニメーションライフサイクル
  export-png.ts        # PNGダウンロード処理
  style.css
src/__tests__/
  effects.test.ts
  renderer.test.ts
  export-png.test.ts
```

## 完了の定義

- 全244種類を切り替えたとき、1つのCanvas上で対応するアニメーションが見える。
- PNGが取得でき、空白ではなくエフェクトが含まれることを目視確認する。
- テストとビルドが通る。未検証事項は報告する。
- READMEに起動コマンドと参照したOSSを記載する。
